# Installation

## Prerequisites

- Blender (version 4.2 or later). Download: <https://www.blender.org/download/>
- Java 8. Download: <https://www.java.com/en/download/manual.jsp>
  (or use an open alternative).
- Make sure both are installed and working (e.g., run java -version in terminal to verify Java, open Blender to verify it launches).

## Download the addon

- Visit the [Releases](https://github.com/moldymoose/MeldrLang/releases) page of this repository.
- Find the latest version and download the add-on zip file.

## Install into Blender

- Open Blender.
- In the top menu go to Edit → Preferences → Add-ons.
- Using the caret drop-down in the top right corner choose "Install From Disk"
- Navigate to the downloaded ZIP and select it.
- Once installed, ensure the add-on is is enabled by checking its box in the add-ons list.
